# Flow State AI

Build a modern, responsive SaaS web application called SmartFlow AI that combines three powerful productivity tools into one unified workspace:

Smart Email Generator

Meeting Notes Summarizer

AI Task Planner & Schedule

The website should feel like a polished, premium AI productivity platform similar to modern SaaS applications. The main purpose is to turn messy notes, meetings, ideas, and instructions into clear emails, summaries, tasks, priorities, and schedules.

1. Overall Design

Create a clean, modern, professional interface.

Visual style

Minimal SaaS dashboard design

White/light-gray background

Dark text

Subtle blue/purple accent colours

Rounded cards

Soft shadows

Clean spacing

Modern typography

Professional icons

Smooth animations

Responsive on desktop, tablet, and mobile

Include light/dark mode

The application should feel intelligent, fast, organized, and easy to use.

2. Landing Page

Create a beautiful landing page with:

Hero section

Headline:

Turn Notes Into Action With AI

Subheading:

Write better emails, summarize long meeting notes, organize tasks, and automatically build your schedule — all in one intelligent workspace.

Primary CTA:

Show three main features:

Transform long meeting transcripts and notes into concise summaries, decisions, and action items.

Turn your notes and priorities into organized tasks and an intelligent daily schedule.

Create a large input area where users can paste long notes, meeting transcripts, ideas, emails, documents, or random thoughts.

Email

Schedule

This entire workflow should happen from one screen.
